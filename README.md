# Chaotic Double Pendulum Wavetables

Generates morphing `.wt` wavetables from the chaotic double pendulum system for use in Surge XT, Cardinal, and other wavetable synths.

## Requirements

- Python 3
- numpy
- scipy

Easy to install all of the dependencies with pip
```bash
pip install numpy scipy
```

## Usage

Clone this repository
```bash
git clone https://github.com/ihateemoji/Chaotic_Pendulum_Wavetables
```
Execute `main.py`
```bash
cd Chaotic_Pendulum_Wavetables
python3 main.py
```

Output goes to `Chaotic_Pendulum_Wavetables/`.
